# 🧛 TVD Quiz

A stylish and interactive quiz website based on **The Vampire Diaries**.

## Features

* 8 multiple-choice quiz questions
* Google Form-style single-page layout
* Interactive answer selection
* Correct answers highlighted in green
* Incorrect selected answers highlighted in red
* Final score displayed after submission
*  60-second quiz timer
* Responsive design for different screen sizes
* Vampire-themed dark UI

##  Technologies Used

* HTML
* CSS
* JavaScript
* Google Fonts
